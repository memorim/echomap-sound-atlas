# EchoMap — интерактивный атлас городских звуков

Интерактивный архив городских звуков. Пользователь исследует записи на карте, фильтрует их по атмосфере и запускает воспроизведение реальных MP3 через HTMLAudioElement.

## Особенности

- географическая карта Leaflet с тайлами OpenStreetMap;
- локальные аудиофайлы с метаданными и источниками CC0;
- фильтрация по городу и характеру звука;
- полевые заметки и статистика архива;
- REST API, SQLite, Zod и интеграционные тесты;
- полностью адаптивный интерфейс.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4700`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```

## Текущий режим работы
Аудиофайлы скачаны из открытой библиотеки Freesound и распространяются по CC0. Источники и контрольные суммы перечислены в `public/audio/sources.json`. Карта показывает звуковые маршруты; происхождение записи указано отдельно. Загрузка собственных аудиофайлов и пользовательские аккаунты в текущий сценарий не входят.
