# EchoMap — интерактивный атлас городских звуков

Интерактивный архив городских звуков. Пользователь исследует записи на карте, фильтрует их по атмосфере и запускает процедурное аудиопревью через Web Audio API.

## Особенности

- картографический интерфейс без стороннего map SDK;
- Web Audio API создаёт уникальное превью для каждой записи;
- фильтрация по городу и характеру звука;
- полевые заметки и статистика архива;
- REST API, SQLite, Zod и интеграционные тесты;
- полностью адаптивный интерфейс.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4700`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```
