# EchoMap — интерактивный атлас звуков

Соединяет карту, фильтрацию звуков и процедурное аудиопревью.

**Тип:** Самостоятельный портфолио-проект. Рабочая демонстрационная реализация; коммерческий запуск и использование реальными пользователями не заявляются.

## Что работает
- Карта, выбор города и атмосферы, карточки записей.
- Процедурное воспроизведение через Web Audio API.
- REST API каталога, статистики и заметок.

## Стек
JavaScript, Web Audio API, Express, SQLite, Zod, HTML, CSS.

## Запуск и проверка
Node.js 24 и pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm start
```

## Технические решения
- Для карты не используется сторонний SDK.
- Аудиопревью синтезируется в браузере из параметров записи.

## Границы готовности
- Аудио — синтез, а не реальные полевые записи. Описания, длительности и координаты — демоданные.
- Загрузки собственных записей, аккаунтов и полноценной картографической подложки нет.
